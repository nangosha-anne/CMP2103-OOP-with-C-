# `speed.cpp`

## OOP Concepts Used

The solution is procedural and does not define a vehicle, distance, or time class. It demonstrates a direct calculation that could later be represented by a domain object.

## Algorithm

1. Read distance and elapsed time.
2. Divide distance by time to calculate speed.
3. Convert units if required and print the result.

## Possible Error Points

- Time must not be zero.
- Distance and time must use compatible units.
- Floating-point arithmetic is needed when the result is not a whole number.
