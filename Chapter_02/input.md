# `input.cpp`

## OOP Concepts Used

This introductory input exercise has no user-defined classes. It demonstrates the basic stream abstraction used by object methods and larger interactive programs.

## Algorithm

1. Prompt for the required value or values.
2. Read them from standard input.
3. Display or process the captured values as required.

## Possible Error Points

- Non-numeric input leaves a numeric stream in a failed state.
- Reading a line after formatted input may consume the pending newline.
- Prompts and output must match the required interaction.
