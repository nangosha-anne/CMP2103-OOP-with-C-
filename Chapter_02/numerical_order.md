# `numerical_order.cpp`

## OOP Concepts Used

The solution uses procedural comparisons and has no user-defined class. Ordering behavior could be encapsulated in a reusable comparator object, but that is outside this exercise.

## Algorithm

1. Read the numbers.
2. Compare them and arrange them according to numerical value.
3. Display the ordered sequence.

## Possible Error Points

- Use numeric types rather than strings, or values will be ordered lexicographically.
- Equal values must be handled without losing an input.
- Ensure all values participate in the ordering.
