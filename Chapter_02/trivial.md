# `trivial.cpp`

## OOP Concepts Used

This small exercise does not use user-defined classes or objects. It reinforces basic C++ statements and program flow before introducing more advanced abstraction.

## Algorithm

1. Initialize or read the values required by the exercise.
2. Perform the stated simple operation.
3. Display the result and terminate successfully.

## Possible Error Points

- Check input types and initialization.
- Operator precedence or integer division may affect simple-looking expressions.
- Match the required output text exactly.
