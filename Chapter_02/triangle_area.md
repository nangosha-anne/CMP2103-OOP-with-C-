# `triangle_area.cpp`

## OOP Concepts Used

No triangle class is defined. The exercise uses procedural input and a geometric formula; a triangle object could encapsulate side lengths and area validation later.

## Algorithm

1. Read the triangle dimensions.
2. Apply the required area formula.
3. Display the area.

## Possible Error Points

- A height or base must not be negative.
- If three sides are used, they must satisfy the triangle inequality.
- Use floating-point arithmetic for fractional dimensions.
