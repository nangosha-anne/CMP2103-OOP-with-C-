# `alphabetical_order.cpp`

## OOP Concepts Used

No user-defined classes or objects are used. The program uses procedural comparison and selection logic; these operations could later be encapsulated in a string utility class.

## Algorithm

1. Read the strings or words.
2. Compare them lexicographically using the character ordering provided by C++.
3. Display them in alphabetical order.

## Possible Error Points

- Uppercase and lowercase characters may sort differently.
- Empty input or whitespace handling can change the comparison result.
- Ensure every value is read before it is compared.
