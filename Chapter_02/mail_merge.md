# `mail_merge.cpp`

## OOP Concepts Used

No custom classes are used. The exercise demonstrates string composition and output; a `Recipient` object could encapsulate the fields in a more reusable implementation.

## Algorithm

1. Read the recipient or message fields.
2. Insert those values into the fixed message template.
3. Print the completed mail-merge text.

## Possible Error Points

- Input containing spaces requires line-based input.
- Fields must be inserted in the correct order.
- Missing whitespace or punctuation produces an incorrectly formatted message.
