# `circle.cpp`

## OOP Concepts Used

The program is procedural and does not define a `Circle` class. Its radius input and area/circumference calculations are natural candidates for encapsulation in a class in a future version.

## Algorithm

1. Read the circle radius.
2. Apply the circle formulas using the stored value of pi.
3. Display the calculated measurements.

## Possible Error Points

- A negative radius is invalid and should be rejected.
- Integer variables lose precision for non-integer radii.
- Use consistent units and check the required number of decimal places.
