# `emissions.cpp`

## OOP Concepts Used

The solution does not define classes or objects. It uses named numeric values and arithmetic; a future design could encapsulate an emission record and its conversion behavior.

## Algorithm

1. Read the input quantity and its relevant rate or factor.
2. Multiply the quantity by the factor to calculate emissions.
3. Present the result using the required unit and format.

## Possible Error Points

- Confirm that the input and factor use compatible units.
- Negative quantities or rates may not be meaningful.
- Floating-point rounding can affect the displayed total.
