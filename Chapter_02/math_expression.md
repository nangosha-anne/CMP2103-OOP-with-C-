# `math_expression.cpp`

## OOP Concepts Used

This is a procedural arithmetic exercise with no custom classes. It relies on C++ operator abstraction and precedence rules supplied by the language.

## Algorithm

1. Assign or read the operands.
2. Evaluate the expression using C++ arithmetic operators and precedence.
3. Print the resulting value.

## Possible Error Points

- Integer division truncates fractional results.
- Parentheses may be needed to make the intended order explicit.
- Division by zero is invalid and must be avoided.
