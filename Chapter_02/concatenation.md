# `concatenation.cpp`

## OOP Concepts Used

No custom classes are used. The program relies on the standard `string` type and its value operations, demonstrating library abstraction without defining a new object type.

## Algorithm

1. Read the text values.
2. Join them in the required order using string concatenation.
3. Print the combined result.

## Possible Error Points

- Using numeric addition instead of string concatenation changes the operation.
- `cin` stops at whitespace; use line input when spaces are valid data.
- Missing separators can make the final text ambiguous.
