# `spelled_out.cpp`

## OOP Concepts Used

The program uses conditional logic and does not define a number-to-words class. A mapping object or formatter class could encapsulate the conversion rules in a more scalable design.

## Algorithm

1. Read the numeric value.
2. Select the word or word combination corresponding to its value.
3. Print the spelled-out result.

## Possible Error Points

- Values outside the supported range need a defined response.
- Zero and negative values often require separate cases.
- Missing spaces or hyphens make otherwise correct words incorrect.
