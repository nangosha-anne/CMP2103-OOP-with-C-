# `ascending.cpp`

## OOP Concepts Used

This solution is procedural and does not define classes. It applies comparison and conditional assignment to values, which could be placed in an object method in a larger design.

## Algorithm

1. Read the values to be ordered.
2. Compare each pair and exchange or select values when they are out of order.
3. Output the values from smallest to largest.

## Possible Error Points

- Reversing a comparison produces descending order.
- Equal values should not be treated as an ordering error.
- Confirm that all input values are initialized before comparison.
