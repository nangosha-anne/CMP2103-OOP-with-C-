# `point_values_order.cpp`

## OOP Concepts Used

The program does not define a point class; it uses separate values and conditional comparisons. A point object with comparison behavior would improve encapsulation in a larger solution.

## Algorithm

1. Read the point values or coordinates.
2. Compare the values using the required ordering rule.
3. Output the points or components in order.

## Possible Error Points

- Confirm which coordinate or value has priority when ordering.
- Equal values need deterministic handling.
- Keep related coordinates together so a point is not accidentally split.
