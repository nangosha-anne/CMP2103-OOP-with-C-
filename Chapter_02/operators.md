# `operators.cpp`

## OOP Concepts Used

No custom class is defined. The exercise demonstrates C++ operator behavior and expressions, including the abstraction that operators provide for built-in values.

## Algorithm

1. Initialize or read the operands.
2. Apply the requested arithmetic, relational, or logical operators.
3. Display the values and results in the required order.

## Possible Error Points

- Operator precedence can change an expression when parentheses are omitted.
- Integer division and remainder differ from floating-point division.
- Division by zero and invalid input must be handled.
