# `matrix.cpp`

## OOP Concepts Used

The matrix is represented with built-in arrays or vectors, not a custom matrix class. This uses container abstraction; matrix operations could be encapsulated as methods in an OOP implementation.

## Algorithm

1. Store the matrix values.
2. Traverse rows and columns with nested loops.
3. Apply the requested matrix operation and print the resulting entries.

## Possible Error Points

- The dimensions of the input matrices must match the operation.
- Row and column indices must remain within bounds.
- Initialize result cells before accumulation, and distinguish matrix dimensions clearly.
