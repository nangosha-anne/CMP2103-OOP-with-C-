# `temperature.cpp`

## OOP Concepts Used

The program uses procedural conversion logic and does not define a temperature class. A unit-aware temperature object could encapsulate conversion and validation in an OOP version.

## Algorithm

1. Read the temperature and source scale.
2. Apply the appropriate conversion formula.
3. Display the target-scale value.

## Possible Error Points

- Use the correct offset and scale factor for the selected conversion.
- Temperature values can be fractional, so avoid integer division.
- Validate the source or target option before calculating.
