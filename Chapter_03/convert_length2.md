# `convert_length2.cpp`

## OOP Concepts Used

The program does not define classes. It demonstrates a second procedural approach to unit conversion, while a conversion class or enumeration could improve reuse and validation.

## Algorithm

1. Read the length and conversion choice.
2. Select the corresponding conversion branch.
3. Calculate and display the target measurement.

## Possible Error Points

- Invalid menu choices need a defined response.
- Check source and target units before applying a factor.
- Avoid integer arithmetic when the converted result is fractional.
