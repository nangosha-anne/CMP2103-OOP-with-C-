# `dataframe.cpp`

## OOP Concepts Used

The program manipulates a tabular data structure procedurally rather than defining a dataframe class. The container provides basic data abstraction, while traversal and output are handled by the program logic.

## Algorithm

1. Create or populate the rows and columns.
2. Traverse each row and its columns with nested loops.
3. Calculate or print the required table values.

## Possible Error Points

- Nested-loop bounds must match the actual dimensions.
- Accessing an invalid row or column causes undefined behavior for raw arrays.
- Keep formatting consistent so columns remain readable.
