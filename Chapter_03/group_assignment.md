# `group_assignment.cpp`

## OOP Concepts Used

This exercise uses procedural input and calculations without custom classes. The group data could be represented by a class or structure with fields and methods in a larger application.

## Algorithm

1. Read the group members or assignment values.
2. Process each value using the required loop or calculation.
3. Produce the requested summary or output.

## Possible Error Points

- Confirm the expected number of entries before indexing arrays.
- Empty groups or missing input may cause invalid averages or output.
- Use the correct accumulation and reset values for each group.
