# `compare_integers.cpp`

## OOP Concepts Used

No user-defined classes or objects are used. The exercise focuses on conditional logic; comparison behavior could be placed in a value object in an OOP design.

## Algorithm

1. Read the integer values.
2. Compare them using relational operators.
3. Report the largest, smallest, or equality result required by the exercise.

## Possible Error Points

- Handle equal values explicitly.
- Do not compare text representations when numeric order is required.
- Ensure every requested value is read successfully.
