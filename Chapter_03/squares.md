# `squares.cpp`

## OOP Concepts Used

This program does not define classes or objects. It demonstrates loops and arithmetic, which could later be provided by a reusable numeric sequence class.

## Algorithm

1. Iterate through the required range of numbers.
2. Square each value.
3. Print the value and its square in the required format.

## Possible Error Points

- Check whether the upper limit is inclusive.
- Squaring large integers can overflow.
- Negative values have positive squares, which should be handled as intended.
