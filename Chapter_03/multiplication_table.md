# `multiplication_table.cpp`

## OOP Concepts Used

No custom objects are used. The exercise applies nested iteration and formatted output; a table generator class could encapsulate this behavior in a reusable program.

## Algorithm

1. Choose the row and column ranges.
2. Use nested loops to calculate each row-column product.
3. Print each product in table form.

## Possible Error Points

- Incorrect loop limits create missing or extra rows and columns.
- Products may overflow a small integer type for large ranges.
- Keep output spacing stable across single- and multi-digit values.
