# `current_calculator.cpp`

## OOP Concepts Used

No custom class is present. The program models an electrical calculation procedurally; a circuit class could encapsulate voltage, resistance, and current relationships.

## Algorithm

1. Read the electrical values required by the exercise.
2. Apply Ohm's law or the specified current formula.
3. Print the calculated current and relevant unit.

## Possible Error Points

- Resistance must not be zero when it is used as a divisor.
- All quantities must use compatible units.
- Use floating-point arithmetic for non-integer current values.
