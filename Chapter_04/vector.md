# `vector.cpp`

## OOP Concepts Used

The program uses the standard `vector` class, demonstrating object use through a library type without defining a custom class. Its methods manage dynamic storage and provide encapsulation of the underlying array.

## Algorithm

1. Create a vector and populate it with values.
2. Access or update elements using vector operations.
3. Traverse the vector and display or calculate the required result.

## Possible Error Points

- Indexes must remain within `size()`.
- An empty vector has no valid element at index zero.
- Changing a vector while holding invalidated iterators or references can cause errors.
