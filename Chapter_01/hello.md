# `hello.cpp`

## OOP Concepts Used

This introductory program does not define classes or objects. It uses the procedural part of C++, including the `main` function, standard output, and the `iostream` library. These are foundational skills used before introducing encapsulation and other OOP features.

## Algorithm

1. Start execution in `main`.
2. Write the greeting to standard output.
3. Return `0` to indicate successful completion.

## Possible Error Points

- The required `iostream` header must be included.
- The output statement must use valid stream syntax.
- If the executable is run from a terminal that closes immediately, the output may disappear before it can be read.
