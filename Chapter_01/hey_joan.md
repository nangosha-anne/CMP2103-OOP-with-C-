# `hey_joan.cpp`

## OOP Concepts Used

No classes or objects are required for this simple output exercise. The program demonstrates a `main` entry point and use of the standard output stream, which are basic C++ building blocks for later object-oriented programs.

## Algorithm

1. Enter `main`.
2. Send the message addressed to Joan to standard output.
3. Return a successful status code.

## Possible Error Points

- Missing `iostream` or incorrect stream syntax causes a compilation error.
- The message must be enclosed in quotation marks.
- Output wording and line breaks may differ if escape sequences are omitted.
