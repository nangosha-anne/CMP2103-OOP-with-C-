# `welcome.cpp`

## OOP Concepts Used

The exercise is procedural and does not use classes or objects. It demonstrates the `main` function and standard output, which are prerequisites for building interactive object-oriented programs.

## Algorithm

1. Enter the `main` function.
2. Print the welcome message to the console.
3. Return `0` to indicate successful execution.

## Possible Error Points

- Include the correct input/output header and use valid stream syntax.
- Keep the required text inside quotation marks.
- Incorrect punctuation, capitalization, or line breaks can make otherwise compiling output incorrect.
