# `journey.cpp`

## OOP Concepts Used

This exercise is procedural and has no user-defined class or object. It practices function execution and console output, which later become operations performed by class methods or objects.

## Algorithm

1. Begin in `main`.
2. Print the journey message or messages in the required order.
3. Finish with a successful return value.

## Possible Error Points

- Text containing spaces must be kept inside one quoted string or printed in separate valid statements.
- Missing headers or semicolons prevent compilation.
- Check the required order and line breaks in the output.
