# `multiplication_table.cpp`

## OOP Concepts Used

This program does not define a class or create objects. It applies procedural control flow, variables, and output. The repeated operation could later be encapsulated in a class method, but the current exercise focuses on loops and console formatting.

## Algorithm

1. Select the number or range for the table.
2. Iterate through each multiplier with a loop.
3. Multiply the selected number by the current multiplier.
4. Print each result in the required table format.

## Possible Error Points

- An incorrect loop bound can omit the first or last row.
- Multiplication and output expressions must use the intended variable.
- Large inputs may exceed the range of an `int`.
- Check spacing and line breaks when comparing output.
