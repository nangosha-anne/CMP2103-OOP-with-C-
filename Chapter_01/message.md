# `message.cpp`

## OOP Concepts Used

The solution does not use classes, inheritance, or polymorphism. It uses the procedural `main` function and standard output to establish the basic program structure used by later OOP exercises.

## Algorithm

1. Start the program in `main`.
2. Display the required message through the output stream.
3. Return from `main` successfully.

## Possible Error Points

- A missing header or semicolon causes a compile-time error.
- Quotation marks must surround the message text.
- Verify capitalization, punctuation, and line endings against the required output.
